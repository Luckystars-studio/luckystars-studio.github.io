PORTFOLIO CASE STUDY

Lucky Stars Portfolio
How I Built This Website

The website you're currently viewing. No template. 100% custom code.

💡 THE CONCEPT

Inspired by Tamal Sen's portfolio style. I wanted something that doesn't just look good but FEELS premium. Dark mode first, glassmorphism cards, minimal but powerful. Goal: Make clients trust me in 5 seconds.

⚙️ WHAT I BUILT

  • 3D Cubes Animation: Floating cubes with CSS 3D transforms + perspective. Moves on scroll with Intersection Observer - no heavy library.
  • Typed Animation: That typing effect "I design for print & digital" - built with custom Typed.js logic. Types, deletes, retypes.
  • Smart Search Overlay: Top right search icon - when you click, it opens overlay that searches my projects instantly. Filters "BBQ", "ESSENCE", "design" without reloading page.
  • Glass UI Cards: Those frosted cards with blur background - backdrop-filter: blur() + rgba borders.
  • Mobile 100% Responsive: Works perfect on your phone like you saw in video. Hamburger menu, touch scroll.
  • Performance: No React, No heavy framework. Just HTML, CSS, Vanilla JS - loads in 1 second even on 3G phone anywhere on the globe.

🛠️ TECH STACK

HTML5 CSS3 (Grid + Flex + 3D) Vanilla JavaScript Typed Animation Intersection Observer API GitHub Pages Hosting

📈 RESULT

1 Year+ experience, Multiple projects, 100% secure, Fast loading, Clean code. This portfolio itself is my best project - it sells my other projects. That's why I put "YOU ARE HERE".
